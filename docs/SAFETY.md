# 安全原則

1. 初期設定では全ての実売買機能を無効化する。認証情報やAPIキーをコミットしない。
2. Jev AIはロジック定義の選択肢IDを一つ返すだけ。追加情報を依存契約に含めない。
3. 新規注文前にブローカー接続、価格鮮度、Bid/Ask、スプレッド、時計差、リスク予算、注文状態を検証する。
4. 注文結果不明（UNKNOWN）では無条件に再発注しない。約定・建玉・予約を照合するまで保全する。
5. 既存建玉の保護は新規注文停止と独立して継続する。
6. デモと実取引の状態・成績・注文ID・リスク予約を混在させない。
7. 接続障害・台帳不一致・予約不整合は新規注文を停止し、監査記録を残す。
8. テスト証跡と管理者の明示承認なしに実売買を開始しない。
